Put your sound effect files here.

Default file names (you can change them at the top of script.js):

  click.mp3      -> general button click
  confetti.mp3   -> "Tap for confetti" button
  blow.mp3       -> blowing the candle
  surprise.mp3   -> surprise button
  meme.mp3       -> tapping a cat meme card

.mp3, .wav and .ogg all work. If a file is missing, that sound is just skipped.
